# Omnitrix Archive

A responsive Ben 10 fan experience built around an interactive Omnitrix command deck. Explore ten classic transformations, compare four generations of the Omnitrix, inspect animated power statistics, and rotate procedural 3D holograms directly in the browser.

## Features

- Interactive Omnitrix and alien holograms powered by Three.js
- Drag-to-rotate and scroll-to-zoom camera controls
- Ten classic alien dossiers with abilities, weaknesses, lore, and statistics
- Search plus power-type and homeworld filters
- Four selectable Omnitrix generations with dynamic accent themes
- Responsive layouts for mobile, tablet, and desktop
- Optional interface audio and reduced-motion support

## Tech stack

- React 19 and Vite
- Three.js, React Three Fiber, and Drei
- Tailwind CSS
- Lucide React
- Framer Motion

## Local development

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```
